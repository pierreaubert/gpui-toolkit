# gpui-themes (lib: `gpui_themes`, version: 0.6.0)

Theme editor and management for GPUI applications.

## Binaries

- `theme-editor` - Interactive theme editor
- `theme-showcase` - Theme gallery and preview

## Purpose

Provides the theming infrastructure for all GPUI-based applications in the project. Read `GPUI.md` at the project root before working on GPUI code.

## Testing

```bash
cargo check -p gpui-themes && cargo clippy -p gpui-themes
```
