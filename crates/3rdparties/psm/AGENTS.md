# psm (Portable Stack Manipulation)

**Vendored 3rd-party crate** -- fork of [psm](https://github.com/rust-lang/stacker/).

Provides stack manipulation and introspection routines. Used for managing stack sizes in deep recursive computations.

## Important Notes

- This is a vendored upstream crate -- minimize modifications
- Has platform-specific assembly code for stack switching
- Original README at `README.mkd`
