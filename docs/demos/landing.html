BUILD WITH THE TOOLKIT

Same UI.
Your language.

Native div-based rendering. Reusable UI and audio controls. D3-inspired primitives and Plotly Express-style charts. Adaptive design tokens and constraint-based layouts.

Read the docs →Follow the tutorial →

Pre-1.0, open source. See the release guide for package availability.

use gpui::div;
use gpui_ui_kit::{Button, ButtonVariant, VStack};

VStack::new()
    .child(div().child("Hi"))
    .child(Button::new("go", "Go")
        .variant(ButtonVariant::Primary))
use gpui_ui_kit_macros::layout;

layout! {
    V {
        Tx "Hi",
        B.primary("Go") #go,
    }
}
from gpui_toolkit import ui

ui.vstack([
    ui.text("Hi"),
    ui.button("Go", id="go", action="app.go"),
])
